# Guide de fonctionnement de l’assistant — TEST

Date : 2 novembre 2026. Statut : document généré, à relire et valider par l’utilisateur.

Pour une nouvelle fiche fournisseur, indiquer son nom et les informations connues.
L’ICE peut rester vide. S’il est fourni, il doit contenir quinze chiffres.
Le tableau présente les informations déclarées et les valeurs reprises par défaut.
Les correspondances de nom ou d’identifiants fiscaux bloquent une nouvelle fiche.
Le code et le nom des fiches correspondantes sont présentés pour vérification.
Une fiche est créée uniquement après confirmation explicite des informations affichées.

Les retours « Réponse correcte » et « À corriger » enregistrent une validation
humaine ou une correction. Ils ne confirment jamais une création dans Sage.
La mémoire conserve ses sources et ses dates. Un document ajouté reste à valider.
Les règles proposées se valident, se modifient ou se refusent directement dans la
conversation. « Quelles règles as-tu retenues ? » les retrouve ; « Oublie cette
règle » désactive la règle ciblée. Aucun panneau séparé n’est nécessaire.
Les valeurs de stock, les soldes et les numéros disponibles doivent être consultés
à nouveau dans les données Sage ; ils ne doivent pas être déduits d’un ancien exemple.

Le modèle utilisé actuellement reste Qwen 2.5 7B dans Ollama. Enregistrer un retour,
valider un document ou exporter un jeu de données ne réentraîne pas ce modèle.
